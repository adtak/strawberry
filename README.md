# くくの ぼうけん

小学生が楽しく九九を学べる、ブラウザで動くアプリです（HTML 1ファイル）。

**あそぶ:** https://adtak.github.io/strawberry/

- ➕ **たしざん** — こたえが10までのたし算バトル。ヒントは10マスのわくで「あといくつで10」も見える
- 📖 **おぼえる** — 段ごとの式と唱え方（さざんが く…）を音声とドット図で
- ⚔️ **たたかう** — 正解するとモンスターに攻撃。まちがえた問題はヒント付きでもう一度出題。クリアでスタンプ
- ⏱️ **タイムアタック** — 60秒で何問とけるか。にがてな問題ほどよく出る
- 📊 **くくひょう** — 81マスが練習するほど色づいていく

スマホ・タブレット（たて）と、テレビやPCの横長画面の両方に対応しています。
学習記録はブラウザの localStorage に保存されます。
